Sobre o Mitoverso

O Mitoverso é uma plataforma educacional desenvolvida com o objetivo de tornar o estudo da Mitologia Grega mais dinâmico, intuitivo e envolvente. Utilizando recursos de gamificação, o projeto incentiva o aprendizado por meio de quizzes, coleções de cards e conteúdos organizados de forma interativa.

Objetivo

O principal objetivo do Mitoverso é oferecer uma ferramenta que auxilie estudantes e professores no estudo da Mitologia Grega, reunindo informações confiáveis em uma interface moderna, acessível e agradável.

Tecnologias Utilizadas

O desenvolvimento do projeto utiliza HTML5, CSS3, JavaScript, Bootstrap, Flask, Jinja e MySQL, permitindo a criação de uma aplicação web responsiva, dinâmica e preparada para futuras expansões.

Principais Funcionalidades

  • Estudo dos deuses, heróis, monstros, titãs e primordiais.
  • Sistema de quizzes interativos.
  • Coleção de cards dos personagens.
  • Sistema de login de usuários.
  • Gamificação com progresso e evolução.

Equipe de Desenvolvimento

O Mitoverso foi desenvolvido como Projeto Integrador do IFRN Campus Ceará-Mirim, reunindo conhecimentos de desenvolvimento web, banco de dados e design de interfaces para criar uma plataforma educacional moderna e interativa.
